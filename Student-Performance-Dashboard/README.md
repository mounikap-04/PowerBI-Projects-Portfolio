# Student Academic Performance Dashboard

##  Project Overview
This project presents a Student Academic Performance Dashboard built using Power BI.  
The dashboard analyzes real student data to understand academic trends and performance insights.

##  Objective
The goal of this project is to explore student performance data and identify patterns related to GPA, department performance, and graduation trends.

##  Key Insights
- GPA Trend Analysis
- Department-wise Performance Comparison
- Graduation Year Insights
- Age vs GPA Relationship
- Academic Performance Distribution

##  Tools & Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Cleaning & Modeling
- Interactive Data Visualization

##  Dashboard Features
- KPI Cards for Key Academic Metrics
- Department Performance Charts
- GPA Distribution Analysis
- Graduation Trend Visualization
- Scatter Plot for Age vs GPA
- Interactive Filters & Slicers
