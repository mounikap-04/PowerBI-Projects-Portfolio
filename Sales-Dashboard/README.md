# Sales Performance Dashboard

## Project Overview
This project presents a Sales Performance Dashboard built using Power BI.  
The dataset contains 2800+ sales records used to analyze sales trends and performance metrics.

## Objective
The goal of this project is to analyze sales data and create interactive visualizations to understand business performance.

## Key Insights
- Total Sales Overview
- Sales by Country
- Yearly Sales Trend Analysis
- Sales by Deal Size
- Performance Comparison Across Regions

##  Tools & Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Cleaning & Data Modeling
- Interactive Data Visualization

## Dashboard Features
- KPI Cards for Total Sales
- Country-wise Sales Analysis
- Year-over-Year Sales Trends
- Deal Size Distribution
- Interactive Filters & Slicers
