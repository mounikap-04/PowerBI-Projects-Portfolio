# HR Analytics Dashboard

##  Project Overview
This project presents an HR Analytics Dashboard built using Power BI.  
The dashboard analyzes employee data to understand attrition trends and workforce insights.

##  Objective
The objective of this project is to explore employee data and identify patterns related to attrition, salary, age, and job roles.

##  Key Insights
- Total Employees & Attrition Rate
- Attrition by Gender
- Attrition by Age & Years at Company
- Salary-wise Attrition Trends
- Education & Job Role Analysis

##  Tools & Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Visualization Techniques

## Dashboard Features
- KPI Cards for Employee Metrics
- Gender-based Attrition Analysis
- Age & Experience Insights
- Salary Distribution Analysis
- Interactive Filters & Slicers
