#  Hospital Management Dashboard – Power BI Project

##  Project Overview
This project presents a complete Hospital Management Analytics Dashboard built using Power BI.  
It analyzes hospital data including doctors, patients, appointments, treatments, and billing information.

---

##  Dashboards Included

###  Doctors Analytics
- Total Doctors
- Specialization Distribution
- Branch-wise Analysis
- Experience Overview

###  Patient Analytics
- Total Patients
- Gender Distribution
- Age Analysis
- Registration Trends
- Insurance Insights

###  Appointment Analytics
- Total Appointments
- Appointment Status
- Doctor-wise Appointments
- Reasons for Visit

###  Treatment Analytics
- Total Treatments
- Revenue by Treatment Type
- Monthly Treatment Trends
- Average Treatment Cost

###  Billing Analytics
- Total Revenue
- Paid vs Pending Analysis
- Payment Method Distribution
- Monthly Revenue Trends
